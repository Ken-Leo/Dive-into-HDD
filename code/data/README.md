# 样例数据

本目录存放书中实验所需的小型数据（单文件 ≤10 MB、单目录 ≤100 MB）。

每个数据集一个子目录，必须包含 `README.md`，说明：

- 数据来源（公司实测 / 论文复现 / 仿真生成）与采集条件；
- 参数（PW50、SNR、码率、采样率等）；
- 许可与脱敏说明；
- 文件格式与校验和（SHA256）；
- 对应章节与实验脚本。

大型或敏感数据（公司 HDD 实测原始信号）不入库，留在外部路径，由环境变量 `HDD_DATA_ROOT` 指定；入库的只是脱敏/抽取后的样例。

加载方式：`hddbook.io.load_dataset("<name>")`。
