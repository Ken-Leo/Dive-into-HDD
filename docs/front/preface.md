# 前言

## 为什么写这本书 {-}

机械硬盘（HDD）是当代数据中心不可替代的大容量存储介质。围绕「90/10」数据分布、面密度演进与自主可控，本书尝试把磁记录读写信道、伺服定位、机电控制、编码与整机工程放在同一坐标系中讲清楚——既给研究生可推导的模型，也给产业工程师可落地的实现要点。

## 素材版权与引用说明 {-}

本书部分章节在参考下列材料的基础上**编译、改写**而成，正文已尽量以教学叙述重写，并在相关处标注来源：

- Piya Kovintavewat 等，HDD 读写信道三卷本（Volume I–III）；
- 《Coding and Signal Processing for Magnetic Recording Systems》（CRC Press）；
- 《Hard Disk Drive Mechatronics and Control》（CRC Press）；
- 《Hard Disk Drive Servo Systems》（Springer）；
- OpenKnowledgeBase 收录的 HDD 领域论文与会议 digest。

上述材料的**原文版权归原作者与出版社所有**；本书中的图除特别注明外均为**原创重绘**，厂商与 IEEE 图按「改编自」标注。参考文献采用 GB/T 7714-2015 格式，正文引用与章末文献表一一对应。

## 本书结构 {-}

全书分为五编：总览与基础、读写信道与信号处理、机电控制与伺服、编码与信息论、整机与前沿，另有附录 A–D（数学工具、术语与符号、可复现仿真、工程实现要点）。各章遵循「直觉 → 模型 → 推导 → 仿真 → 工程要点」的教学链，实验代码见随书仓库 `code/`。

## 阅读建议 {-}

- 研究生读者：重点阅读各章的模型与推导，配合附录 A 与仿真实验；
- 产业工程师：重点阅读各章的「工程实现要点」与附录 D，可按需跳过冗长推导；
- 首次接触 HDD 的读者：先读第 1–3 章，再按兴趣选读后续编章。
