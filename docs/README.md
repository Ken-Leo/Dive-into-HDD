## 编著约定

- **章节主体**：以磁记录读写信道/信号处理为主线（Piya 三卷本 + 《磁记录系统的编码与信号处理》），并纳入伺服定位/机电控制/主轴电机等整机关键技术。
- **目标读者**：数据存储专业研究生 + 产业工程师。
- **撰写风格**：深入浅出教学型，学术准确性优先，兼顾工程落地，每章小结 + 习题。
- **总篇幅**：约 500–600 页（中大型，已定稿）。
- **素材指引**：见 `plan/book-outline.md` 第八节的素材索引与第六节的覆盖核对。
- **版权**：前言设「素材版权与引用说明」，厂商/IEEE 图原创重绘。

## 目录结构约定

- `docs/plan/`：策划类文档（定位、风格、提纲）。
- `docs/`：各章正文（markdown），进度按 `book-outline.md` 提纲推进。
- `figures/`：各章图片（对齐参考译书 `images/<章>/` 的组织与命名）。
