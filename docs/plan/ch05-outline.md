## 六、工程实现要点（面向产业工程师，5 条）

1. **写场梯度预算**：a 由 QHc 与梯度决定，梯度不足时 a→⟨D⟩/π 上限不可突破；PW50 下限、NLTS 幅度与写头极靴 R/W_write 需联合设计（式5-4、5-5、5-14）。
2. **读出灵敏度与 PW50 折中**：GMR/TMR 效率 E≤0.5、屏蔽间距 G 与净磁间距 γ 决定 η；G 减小提升分辨率但降低 E，需给出 E-PW50 帕累托曲线。
3. **SNR 报告规范**：任何 BER 结果必须同时声明 SNR 定义（Et/Nα 而非 Et/N0）、α、OSR、码率与目标响应；否则不同方案不可比（式5-17、5-18）。
4. **信道标定三步法**：实测 PW50/roll-off → 反演 a 与 G；实测噪声谱 → 反演 σj/σw；梯度迭代 → 校准 M0 至目标 α（例5-6 流程，<20 次收敛）。
5. **读信道链路时序约束**：TA 检测/修正在 ADC 前后越早越好，否则定时环失锁；AGC 增益误差与 ADC 量化噪声需联合预算，均衡器置于 ADC 后将加大定时环延迟（Piya Ch6 §6.6）。
