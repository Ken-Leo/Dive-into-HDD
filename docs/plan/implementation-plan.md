## 2. 篇幅与产能基线

### 2.1 篇幅换算

- 目标成品 500–600 页（16 开技术书，含图、表、公式、习题）。
- 按技术书排版密度 650–700 汉字/页折算，正文约 **31–40 万汉字**。
- 本计划控制目标：**排版量约 480 页 / 正文约 31.4 万汉字 / 图约 320 幅**，经排版与图件扩充后落在 500–600 页区间。
- 每章正文 1.2–2.1 万汉字；第 4 章按「浓缩提要 + 附录 A」处理，压至 0.7 万汉字。
- **口径差异说明**：独立评审按 700–900 字/页折算得 35–42 万字；本计划按含约 320 幅图的排版密度（650–700 字/页）折算为 31.4 万字。差异来自图密度假设——若图件降至约 200 幅，正文应上调至 36–40 万字。另：第 5 章样章大纲实测 12 幅图/26 页（约 0.46 幅/页），低于本表 20 幅的初估；若全书按此密度，图数约 220–280 幅。**M0 样章排版后按实际图密度与字数复核，锁定最终口径并同步修订本表。**

- 第 18 章依赖全书定稿；前言依赖全书结构定型。

### 3.2 写作顺序（按依赖与素材成熟度）

**第 5 章（样章）→ 第 4 章 → 第 6 章 → 第 7 章 → 第 8 章 → 第 1 章 → 第 2 章 → 第 3 章 → 第 9 章 → 第 10 章 → 第 11 章 → 第 12 章 → 第 13 章 → 第 14 章 → 第 15 章 → 第 16 章 → 第 17 章 → 第 18 章 → 附录 A/B/D → 附录 C → 前言 → 全书整合。**

理由：
1. 第 5–8 章是全书技术主干、素材最完整，且是后续章节的引用基础；先写可尽早暴露素材与风格问题。
2. 第 4 章短，且是第 5 章的前置，紧随样章。
3. 第 1–3 章是导论性质，待主干定型后写，避免导论承诺与正文能力脱节。
4. 第 16 章前沿内容依赖最新文献，靠后写；第 18 章最后写。
5. 附录 B（术语/符号）与各章并行维护，先建 v0.1 再随章更新。

## 6. 写作规范

### 6.1 目录与命名

- 章节正文：`docs/chapters/chNN-<slug>.md`（例：`ch05-recording-channel.md`）。
- 图件：`figures/chNN/figNN-MM-<slug>.{drawio,svg,png}`；每图附源文件。
- 仿真代码：`code/appendix-c/chNN/section-N-M.py`，附运行说明与依赖版本。
- 素材包：`docs/plan/materials/chNN.md`；章节大纲：`docs/plan/chNN-outline.md`。
- 术语表：`docs/plan/terminology.md`（附录 B 的工作版）。

### 6.2 正文与公式

- 每节遵循「直觉 → 模型 → 推导 → 仿真 → 工程要点」；不得只给结论。
- 公式用 LaTeX，章内编号 `(N-1)`；每个公式给物理含义、量纲、适用条件；关键公式须有推导要点或仿真验证。
- 符号统一：先建术语/符号表（附录 B v0.1），跨编符号冲突须在表中消解。
- 中文表述，术语首次出现给中英文对照；避免直译腔与「翻译体」长句。

### 6.3 图与版权

- 全部图**原创重绘**；源自厂商/IEEE/原书的图标「改编自 [n]」，并在前言版权说明中统一声明。
- 优先用 matplotlib/Python 生成曲线图（可复现、可入库脚本）；示意图用 draw.io 并保存源文件。
- 图注中文，标注图号；正文引用图号必须存在。
- 不得直接嵌入原书截图（除明确授权的公开图）。

### 6.4 引用与文献

- 参考文献用 GB/T 7714-2015 顺序编码制；正文上标 `[n]`。
- 每章 ≥15 条；优先 2015 年后 IEEE Trans. Magn./JAP/JSPS 等同行评议文献 + 领域经典教材。
- 每条文献须核验（DOI/ISBN/标准号）；AI 生成的文献必须逐条核验，禁止凭记忆编造。
- 厂商白皮书/标准（SATA、NVMe、ZAC 等）标注版本与访问日期。

### 6.5 章节结构

统一按 `docs/templates/chapter-template.md`：本章导读（学习目标）→ 分节正文 → 工程实现要点 → 本章小结 → 习题（基础/进阶/仿真）→ 参考文献 → 图清单 → 术语与符号。

### 6.6 写作标记

起草阶段统一使用 `[待核]` `[需图]` `[需数据]` `[引用待补]` `[待作者确认]`；定稿前清零或转为明确注释。

## 7. 质量门禁（每章验收清单）

一章只有全部通过才可标记 `done`：

1. **结构**：模板要求的全部部件齐备；学习目标与小结一一对应。
2. **篇幅**：汉字数在预算 ±10%，页数估算达标。
3. **公式**：每个公式有物理含义、量纲、适用条件；关键公式有推导或仿真佐证；符号在附录 B 中登记。
4. **图件**：图数与预算一致；全部原创重绘或标注来源；正文引用与图号一一对应；源文件入库。
5. **仿真**：每个仿真示例可运行（脚本+参数+预期结果）；结果与正文数值一致。
6. **引用**：≥15 条且逐条核验；正文引用与文献表一一对应；无编造文献。
7. **术语**：与术语表一致；首次出现中英对照；无同名异义/同义异名。
8. **事实**：年份、标准号、厂商数据、量级经核验；无 `[待核]` 残留。
9. **交叉引用**：章/节/图/表/公式/习题引用全部有效。
10. **原创性**：无整段照搬译稿；改写处标注「改编自 [n]」；语言风格统一。
11. **工程要点**：每章至少 3 条可落地的实现要点（面向产业工程师）。
12. **习题**：8–12 题，分三类，答案要点齐全，仿真题有对应代码。
13. **实验代码**：正文引用的每个实验/图都有对应脚本；`--quick` 可跑通，冒烟测试通过；参数、seed、预期结果齐全；运行时间达标。
14. **图文一致**：图由脚本生成，`figures/manifest.yaml` 条目完整（脚本、命令、输出、SHA256、版权）；正文图号与 manifest 一一对应。
15. **代码版权**：移植代码标注来源项目、原作者与许可；未声明许可的项目已取得作者授权或标注「改编自」；数据来源与授权说明齐全。
16. **排版构建**：`tools/build_book.py` 构建通过（无 `!` 错误、无 undefined reference/citation）；章/节/图/表/公式编号与正文引用一致；章末参考文献由 `book/reference.bib` 生成并逐条核验；PDF 版面检查（字体嵌入、无严重 overfull、图表不跨页断裂）。
