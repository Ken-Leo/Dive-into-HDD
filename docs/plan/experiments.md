## 一、总原则

1. **实验服务于论证**：每个实验必须绑定正文的具体论断、图或习题，正文以 `{{exp:ID}}`、`{{code:script}}`、`{{fig:ID}}` 引用；无正文引用的实验不进书。
2. **最小可复现**：脚本 + 参数 + 固定 seed + 预期结果 + 运行时间；`--quick` 模式 ≤60 s，完整模式 ≤10 min。
3. **共享库优先**：算法进 `code/hddbook/`，脚本只做编排；禁止跨章复制粘贴。
4. **可验证**：每个实验给出可判定的验收指标（BER 斜率、与理论/参考实现误差、双射验证、收敛次数等），并配冒烟测试。
5. **版权合规**：移植代码标注来源项目、原作者、授权方式；未声明许可的项目须作者书面授权或重写；MATLAB 专有工具箱依赖的代码只作参考或改写为 Python。
6. **数据合规**：小型样例入库（≤10 MB/文件）；公司实测数据脱敏后入库，原始数据留在外部路径（`HDD_DATA_ROOT`）。

## 四、代码架构

```
code/
├── hddbook/
│   ├── channel.py        # PMR/LMR 脉冲、dibit、抖动、AWGN、过采样
│   ├── media_noise.py    # DC 剩磁/翻转噪声、σj/σa、SNR 定义族
│   ├── equalization.py   # MMSE/GPR 目标、LMS、2D 均衡
│   ├── detection.py      # Viterbi/NPML/PDNP/DD-NPML/BCJR
│   ├── timing.py         # PLL、Farrow、前导估计
│   ├── coding/           # RLL 码表、RS/LDPC、turbo
│   ├── servo.py          # 执行器/主轴/双级控制（新）
│   ├── capacity.py       # 信道容量/可达速率（新）
│   ├── metrics.py        # BER/FER/SNR/EXIT 度量
│   ├── plotting.py       # 统一绘图与导出
│   └── io.py             # 数据加载、CSV、manifest
├── experiments/          # chNN_<slug>.py（E1/E2）
├── tests/                # 冒烟与回归（pytest）
├── data/                 # 小样本数据 + README
└── results/              # 运行产物（CSV/JSON，图入 figures/）
```

**接口约定**：每个实验脚本 `main(argv)` 可导入；参数含 `--seed/--out/--quick/--data`；返回输出路径；写入 `results/<exp_id>.csv` 与 `figures/...`，并调用 `hddbook.io.record_figure()` 更新 `figures/manifest.yaml`。

## 五、复现与验收标准

| 级别 | 标准 | 验证方式 |
|------|------|----------|
| V1 可运行 | `--quick` 在干净环境跑通，输出文件存在 | CI 冒烟测试 |
| V2 结果可信 | 与解析解/参考实现/文献数值一致（误差阈值随实验定义） | 对拍脚本、断言、审读人复核 |
| V3 图文一致 | 书中图与脚本输出一致（SHA256 或像素比对） | `figures/manifest.yaml` + 回归 |
| V4 可教学 | 参数可解释、有预期结果说明、习题可复用 | 作者审校 |

**每实验必须交付**：脚本、参数说明、预期结果（数值/曲线范围）、运行时间、seed、数据来源、验收断言、版权标注、对应正文位置。
